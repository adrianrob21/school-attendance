# Calendar year — eight additional month prompts

Created with the built-in `image_gen` tool. The approved February, June, October and December concepts remain part of the full-year set. See [the twelve-month gallery](calendar-concept.md) and [the original four prompts](calendar-concept-image-prompts.md).

Each prompt below is an independent edit of an approved page. Reference images were viewed before generation; final images are saved in `docs/concepts`. All dates use 2026; day12 and birthdays8/22 are simulated visual examples.
